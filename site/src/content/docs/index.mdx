## What is plate solving?

Plate solving is how imaging software finds out exactly where a photo was taken on
the sky: it matches the pattern of stars in the image against a star catalogue.
Software such as N.I.N.A. uses the answer to centre a target after a slew, to return
to the same framing on another night, and to correct the mount's idea of where it is
pointing.

arcsec is the program that does the matching. It runs on your own computer, needs no
internet connection to solve, and is free.

## Built on ASTAP

arcsec would not exist without [ASTAP](https://www.hnsky.org/astap.htm) by Han Kleijn,
and owes it two things in particular:

- **The method.** ASTAP's way of recognising stars, describing each group of four by
  the ratios of the distances between them, which stay the same however the image is
  rotated, scaled or flipped, is the idea arcsec is built on. Kleijn describes it
  openly in
  [ASTAP star pattern recognition algorithm and astrometric (plate) solving](https://www.hnsky.org/astap_astrometric_solving.htm).
- **The catalogues.** arcsec reads ASTAP's star catalogue files, so the same
  catalogues serve both programs.

ASTAP is licensed under the Mozilla Public License 2.0. arcsec is an independent
program and contains no ASTAP code. ASTAP does much more than plate solving: if you
use its viewer, stacking or photometry, keep it.
